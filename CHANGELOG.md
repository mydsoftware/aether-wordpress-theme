# Changelog

## [1.0.0] - 2026-08-29

### Added
- هسته تم Aether با معماری modular
- Design System کامل (Color, Typography, Spacing, Radius, Shadow Tokens)
- سیستم Header با Sticky، Topbar، Mobile Menu، Cart، Search
- سیستم Footer چندستونه
- Layout Engine (Boxed, Full Width, Sidebar Left/Right, No Sidebar)
- یکپارچه‌سازی WooCommerce
- Dark Mode مبتنی بر data-theme
- پشتیبانی کامل RTL و فارسی با Vazirmatn
- پنل تنظیمات ادمین با تب‌های متعدد
- Dashboard، Demos، License pages
- REST API داخلی (`aether/v1`)
- Theme Schema machine-readable
- سیستم Snapshot برای versioning تنظیمات
- Security layer (Nonce, Capability, Sanitization)
- Accessibility basics (skip link, focus, ARIA)
- Onboarding redirect بعد از فعال‌سازی
- سازگاری اولیه با Elementor و SEO plugins

### Notes
- Demo Importer کامل در نسخه‌های بعدی
- License Server connection modular و آماده
- AI Agent در این نسخه فعال نیست (فقط زیرساخت)
